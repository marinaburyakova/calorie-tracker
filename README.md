A premium, boutique-style Single Page Application for tracking daily calorie intake with AI-powered nutrition assistance. Built with React, Vite, Tailwind CSS, and GSAP animations.

![Preview](https://via.placeholder.com/800x450/1a1a2e/ffffff?text=ÉLEVÉ+Calorie+Tracker)

## Features

### Core Functionality

- **Track Daily Calories** - Log meals and monitor your daily intake
- **Smart Calculation** - Automatic calorie calculation with weight/portion support
- **Meal Categories** - Breakfast, Lunch, Dinner, and Snacks
- **Progress Tracking** - Visual progress bar with color-coded alerts
- **Local Storage** - All data persists in your browser

### AI Nutrition Assistant

- **Intelligent Chatbot** - Get answers about any food product
- **Calorie Information** - Detailed nutritional data for 60+ products
- **Food Pairing** - Smart recommendations for food combinations
- **Product Comparison** - Compare calories between different foods
- **Meal Planning** - Generate meal plans for different goals
- **Personalized Advice** - Get tailored nutrition recommendations

### Premium Design

- **Glassmorphism & Neumorphism** - Modern, premium visual style
- **Light/Dark Themes** - Full theme support with smooth transitions
- **Responsive Design** - Perfect on desktop, tablet, and mobile
- **GSAP Animations** - Smooth stagger effects and micro-interactions
- **Bento Grid Layout** - Modern, organized interface

### Smart Input Processing

- **Natural Language Processing** - Understands "chicken 200g", "sandwich 2 pcs"
- **Complete Dishes Recognition** - Recognizes "chicken with rice", "borscht"
- **Weight & Quantity Support** - Supports grams, kilograms, and pieces
- **Smart Suggestions** - AI-powered tips for missing information
